abstract: We propose a human-in-the-loop method for generating preservation metadata
  for research dataset segments using a conversational GPT-based assistant. Through
  interactive prompts, the agent engages users in documenting the content, provenance,
  and context of individual files. The method outputs both a human-readable markdown
  summary and a METS v2-compliant metadata package with embedded JPCOAR2-style descriptions.
  By integrating metadata creation into the research workflow itself, this approach
  lowers the barrier to producing submission-ready information packages while preserving
  interpretive and contextual knowledge essential for long-term access.
